# Flutter App

Flutter ile geliştirilmiş Odin Weather uygulaması

## Kurulum

```bash
flutter pub get
flutter run
```

## Özellikleri

- 🌤️ Gerçek zamanlı hava durumu
- 📍 GPS konum algılama
- 🗺️ Google Maps entegrasyonu
- ⚠️ Hava uyarıları
- 🌙 Koyu mod desteği
- 📱 Responsive tasarım
- 💾 Offline desteği
